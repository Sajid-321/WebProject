# Pharmacy_Application SPA

## 📌 Project Description

ABC Pharmacy Medicine Management System is a Single Page Application (SPA) developed using **ASP.NET Core Web API** and **JavaScript framework** 
to manage medicines and maintain medicine sales records.

The application allows users to:
- Add medicines
- View medicine inventory
- Search medicines
- Update and delete medicine
- Store data using JSON files

---

# 🚀 Technologies Used

## Backend
- ASP.NET Core Web API (.NET 8)
- C#

## Frontend
- JavaScript
- HTML
- CSS
- Bootstrap

## Data Storage
- JSON File Storage
